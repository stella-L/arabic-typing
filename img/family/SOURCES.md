# Family member cards

These SVG cards were created in this project for Arabic family vocabulary.

Used for:
- `grandfather.svg`: `جَدٌّ` / 할아버지
- `grandmother.svg`: `جَدَّةٌ` / 할머니
- `father.svg`: `أَبٌ` / 아버지
- `mother.svg`: `أُمٌّ` / 어머니
- `brother.svg`: `أَخٌ` / 형제
- `sister.svg`: `أُخْتٌ` / 자매
