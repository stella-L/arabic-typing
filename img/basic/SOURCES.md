# Basic meaning cards

These SVG cards were created in this project for short abstract vocabulary.

Used for:
- `yes.svg`: yes / `نَعَم`
- `no.svg`: no / `لَا`
- `question.svg`: question words such as `هَلْ`, `أَيْنَ`, `كَيْفَ`
- `good.svg`: good / fine expressions
