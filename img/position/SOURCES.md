# Position diagrams

These SVG diagrams were created in this project for Arabic position/preposition vocabulary.

Used for:
- `front.svg`: `أَمَامَ` / 앞에
- `behind.svg`: `خَلْفَ` / 뒤에
- `beside.svg`: `بِجَانِبَ` / 옆에
- `under.svg`: `تَحْتَ` / 아래에
- `on.svg`: `عَلَى` / 위에, 접촉
- `above.svg`: `فَوْقَ` / 위에, 공중
