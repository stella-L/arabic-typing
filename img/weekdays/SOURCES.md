# Weekday calendar cards

These SVG calendar cards were created in this project for Arabic weekday vocabulary.

Used for:
- `saturday.svg`: `يَوْمُ السَّبْتِ` / 토요일
- `sunday.svg`: `يَوْمُ الْأَحَدِ` / 일요일
- `monday.svg`: `يَوْمُ الِاثْنَيْنِ` / 월요일
- `tuesday.svg`: `يَوْمُ الثُّلَاثَاءِ` / 화요일
- `wednesday.svg`: `يَوْمُ الْأَرْبِعَاءِ` / 수요일
- `thursday.svg`: `يَوْمُ الْخَمِيسِ` / 목요일
- `friday.svg`: `يَوْمُ الْجُمُعَةِ` / 금요일
